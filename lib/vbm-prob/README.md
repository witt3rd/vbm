# vbm-prob

**Exact discrete probability, valid by construction and kept valid by every operation: a value that is a probability, or a finite distribution of them, and every function either returns a value of those types or refuses with a typed value, with proofs.**

> **Status: pre-release.** The specification, its proofs and the known-answer vectors are in; the library is not yet released. Nothing is published to a package registry.

## Build and test
Prerequisites: `git`, [mise](https://mise.jdx.dev). `mise exec -- scripts/tier1.sh` is the gate (Lean, pinned in `mise.toml`). The claims and the theorems that prove them are in `docs/proof-ledger.md`, generated by the gate.

## How it is built
Agents write it under mechanical gates instead of line-by-line review, to the [VBM standard](https://github.com/witt3rd/vbm). It lands directly on `main` with `.land/land-direct`, a pinned copy of [vbm-land](https://github.com/witt3rd/vbm-land).

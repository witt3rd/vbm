# vbm-rng

**Deterministic, splittable pseudo-random generators with specified streams: the same seed always gives the same bytes, and exactly reproducible sampling primitives (uniform integers in a range, uniform fractions in exact arithmetic) for simulation and experiments.**

> **Status: pre-release.** The skeleton. Nothing is published to a package registry.

## Build and test
Prerequisites: `git`, [mise](https://mise.jdx.dev). `mise exec -- scripts/tier1.sh` is the gate (Lean, pinned in `mise.toml`). The claims and the theorems that prove them are in `docs/proof-ledger.md`, generated by the gate.

## Conformance
The known-answer vectors of `docs/spec.md` part V are in [`vectors/known-answers.txt`](vectors/known-answers.txt), one per line, and each is a kernel-checked `example` in `VbmRngProofs/Vectors.lean` (generated from the text file). `scripts/test_vectors.sh` checks that the two agree, that every vector holds, and that a wrong vector is detected. The raw stream of key 0 reproduces the published SplitMix64 outputs. A change that alters a line of the file is a breaking change.

## How it is built
Agents write it under mechanical gates instead of line-by-line review, to the [VBM standard](https://github.com/witt3rd/vbm). It lands directly on `main` with `.land/land-direct`, a pinned copy of [vbm-land](https://github.com/witt3rd/vbm-land).

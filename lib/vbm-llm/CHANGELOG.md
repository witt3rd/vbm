# Changelog

## 0.2.0

- The library is released from the family repository (`lib/vbm-llm`), where its gate, its areas and its signed `vbm-llm/vX.Y.Z` tags now live. It requires `vbm-json` by the relative path `../vbm-json` (released as 0.2.1, with `vbm-simd` 0.2.0): the tree this tag records for its dependencies is a released one. The specification and the proofs are unchanged; the old standalone repository is archived.

## 0.1.0

- The first release, made from the standalone repository.

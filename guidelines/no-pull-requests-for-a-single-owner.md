# No pull requests for a single owner

A pull request is a shared place for review and consent. When one owner's agents are the only writers, and a mechanical gate decides, a pull request adds a queue and conflicts without adding information: dozens of them open at once sit for hours and collide.
Land directly instead (see `single-lander.md`). Keep pull requests where outsiders contribute, and where main deploys. A registry of other people's repos is such a place: an entry is a pull request, and the score is committed only by the scoring job.
